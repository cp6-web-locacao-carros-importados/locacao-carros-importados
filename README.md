# ImportedRent — Locação de Carros Importados

Checkpoint 6 · Web Development · FIAP (1ESPG)

Sistema web de locação de carros importados feito com **React + Vite + Tailwind CSS** e rotas com **react-router-dom**.

## Estrutura

```
src/
├── components/   # Navbar, Footer, Card
├── pages/        # Home, Carros
├── data/         # lista de carros
├── App.jsx       # rotas (BrowserRouter)
└── main.jsx
```

## Rodando

```bash
npm install
npm run dev
```
